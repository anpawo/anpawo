Fifth-year student at Epitech Paris, back from an exchange year at CSULB. I build software that removes repetitive work, these days mostly by putting LLM agents to work.

### Relevant Contributions

- [Lightpanda](https://github.com/lightpanda-io/browser), the headless browser built for AI agents ([All contributions](https://github.com/lightpanda-io/browser/pulls?q=is%3Apr+author%3Aanpawo)) (2026)

### Relevant Projects

- [Fleet](https://github.com/anpawo/fleet) (2026-now)  
A macOS background app that shows every Claude Code session on the machine (done, working, or waiting on you) the moment you go idle; a click brings its terminal tab back  
In Swift and AppKit
- [my-apps](https://github.com/anpawo/my-apps) (2026-now)  
Little macOS apps made for my own needs, each one running on my Mac today  
[Vibe Code X](https://github.com/anpawo/my-apps/tree/main/vcx), a native window for Claude Code, Codex and Qwen; [mac-guard](https://github.com/anpawo/my-apps/tree/main/mac-guard), which pauses what is about to freeze the Mac; an ⌘Tab switcher, a launcher, an autocorrect and more
- Auto Mail (2026-now)  
A Gmail triage bot: one batched LLM call scores every mail, and plain code, not the model, decides what may be deleted  
What's left becomes a deck of cards in an Android app: swipe to reply, snooze, or ban a sender for good  
Node.js on GitHub Actions, Kotlin and Jetpack Compose
- [Video-Code](https://github.com/anpawo/video-code) (2024-now)  
Videos written as code: shapes declared, placed and animated in Python, rendered frame by frame  
C++ engine on Vulkan and Qt6, encoded with FFmpeg  
Made 2.1× faster: 17 → 9.5 ms per 1080p frame, peak memory down 33%  
Epitech end-of-studies project
- The [Glados](https://github.com/anpawo/glados) (2024-2025)  
An imperative, statically-typed language: tokenizer, parser, optimization passes, bytecode compiler and a stack-based VM with tail calls  
In Haskell, in a team of 5  
Standard library with I/O, random, structures, closures and atoms
- [C-Lib](https://github.com/anpawo/c-lib) (2022-2023)  
My own C standard library, written in an object-oriented style during my first year at Epitech
- Notif-Pogo (2022-2023)  
A Discord bot that scrapes Pokémon Go spawns all around the world, with a wide variety of filters
